Как пользоваться графиком

Поиск

Минимум 2 символа. Debounce 280 мс. Ищет по словам с учётом словоформ, синонимов и небольших опечаток. Если точных совпадений мало — показывает близкие по смыслу с пометкой «похоже по смыслу». Пустой экран не показывается: либо результаты, либо весь каталог с предупреждением.

Годы

Каталог сгруппирован по годам от старых к новым. Можно выбрать конкретный год или «все годы».

Период

Клик по году → список годов. Клик по месяцу → сетка месяцев. Клик по любому дню недели — выбор недели целиком. «ОК» подтверждает выбор.

Будущие игры

Игры, которые ещё не вышли, подсвечены бледно с замком и надписью «кто возьмёт — тот лох».
